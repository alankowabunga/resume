# 陳昱任 / Chen Yu Jen — Resume

Static two-language resume. No build step: plain HTML plus one stylesheet.

| File | |
|---|---|
| `index.html` | 中文版 |
| `en.html` | English |
| `style.css` | shared layout, theming and A4 print rules |
| `img/` | portrait, cover, certificate scans |

**PDF**: open either page and use the Print / Save as PDF button. The print
stylesheet lays the content out on A4 — two résumé pages plus a certificate
appendix. No PDF is committed, so what you print is always current.

Published with GitHub Pages.
